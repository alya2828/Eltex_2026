# Raw Socket UDP Echo Client-Server

## Описание

Проект реализует echo-client и echo-server с использованием **raw sockets (AF_INET, SOCK_RAW)** и протокола **UDP**.

Сервер:
- принимает сообщения от клиентов
- ведёт индивидуальный счётчик сообщений для каждого клиента (IP:PORT)
- отвечает сообщением + номером сообщения
- сбрасывает счётчик при получении `CLOSE`

Клиент:
- отправляет UDP-пакеты через raw socket
- получает ответ от сервера
- корректно завершает работу при SIGINT/SIGTERM
