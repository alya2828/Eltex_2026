##  Что это

- сервер
- несколько клиентов

Сервер управляет клиентами через TCP-соединение.

---

### Сервер:
- ждёт подключения клиентов
- показывает меню управления
- отправляет команды всем клиентам

### Клиенты:
- подключение к серверу (127.0.0.1:5000)
- получение команд через TCP
- выполнение действий по командам

---

### Основные функции сервера:
- `accept_thread()` — принимает клиентов в фоне
- `send_all()` — отправляет команду всем клиентам
- `main()` — меню управления

## ЧТО НАМУДРИЛА 

### Потоки 
используются для того, чтобы:
- одновременно принимать новых клиентов (`accept`)
- и при этом не блокировать работу меню сервера

 Без потоков сервер бы “зависал” на `accept()` и не смог бы отправлять команды.(ПРОВЕРИЛА)

---

### Мьютекс 
 для защиты общего ресурса — массива клиентов:

- `clients[]`
- `client_count`

- один поток добавляет клиентов
- другой поток отправляет им команды
