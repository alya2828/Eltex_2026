# Задание 2 — Kernel Module (procfs)
## Описание задачи
В рамках задания был разработан модуль ядра Linux, обеспечивающий взаимодействие между userspace и kernel space через интерфейс /proc. При загрузке модуля создаётся виртуальный файл /proc/hello, через который реализован обмен данными: запись и чтение данных.

## Сборка проекта

- make

В результате сборки создаётся файл модуля ядра:

my_proc.ko

##Загрузка модуля выполняется командой:

- sudo insmod my_proc.ko

После загрузки модуль регистрируется в ядре и создаёт файл /proc/hello. 

##Проверка загрузки выполняется командами:

- lsmod | grep my_proc 
- sudo dmesg | tail

Работа с модулем осуществляется через:

echo "text" > /proc/hello - запись данных 
cat /proc/hello -  чтение данных

##Выгрузка модуля выполняется командой:

- sudo rmmod my_proc

После выгрузки файл /proc/hello удаляется.

3.добавлено корректное завершение строки символом '\0'
4.реализована проверка *offp для предотвращения бесконечного чтения файла
